Política de privacidad

El tratamiento de datos en CITAS ALTOQ se realiza para administrar citas CRED, pacientes, apoderados, contactos, importaciones, recordatorios y seguridad de acceso.

  • Datos tratados: identificación del paciente y apoderado, historia clínica o código CRED, establecimiento, red, microred, citas, estado de confirmación, teléfonos, consentimientos y registros de auditoría.
  • Finalidades: autenticar usuarios, consultar información CRED, programar y confirmar citas, enviar recordatorios permitidos, mantener trazabilidad y proteger la operación del sistema.
  • Acceso: solo personal autorizado por rol y ámbito. El administrador maestro puede configurar qué establecimientos reciben recordatorios CRED.
  • Encargados: pueden intervenir proveedores tecnológicos necesarios para autenticación, alojamiento, mensajería WhatsApp, soporte y monitoreo, bajo deber de confidencialidad y seguridad.
  • Conservación: los datos se guardan durante el tiempo necesario para la finalidad operativa, auditoría, cumplimiento normativo y atención de incidencias.
  • Derechos ARCO: el titular o representante puede solicitar acceso, rectificación, cancelación u oposición de sus datos ante la entidad responsable del servicio.
  • Seguridad: se aplican controles de acceso, roles, trazabilidad y validaciones para reducir accesos no autorizados, pérdida, alteración o uso indebido.
